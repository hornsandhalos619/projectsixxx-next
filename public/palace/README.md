# Palace shell (Blender)

Export your Palace of Wonders case/rooms from Blender as a single `.glb` (or place multiple assets here) named:

`shell.glb`

Path the experience expects: `/palace/shell.glb`

Until that file is present, `/palace` runs the procedural photoreal halls (Vestibule → Duality → twin mazes → Gallery → Cloister → OVERMIND Sanctum → Threshold of Death).

Recommended export:
- Apply transforms
- Y-up, meters
- Embed textures
- Keep doorway pivots near room centers documented in `config/palace.ts`
